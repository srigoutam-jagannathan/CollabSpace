# Expo Mastery Skill
## Standards
- Use Expo Router v3 for file-based routing.
- Prefer `Link` from `expo-router` over manual navigation.
- Use `expo-image` for high-performance image caching.
- Always check compatibility with Expo SDK 50/51.
## Workflow
1. When asked to create a screen, default to the `app/` directory.
2. Ensure `_layout.tsx` files handle the rendering of children properly.
